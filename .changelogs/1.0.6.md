* Wawel Auth now only supplies skins and capes. Drawing them moved to Salamander: modern 64x64 skins with slim arms, flat and 3D skin layers, see-through skin pixels, and the related mod compatibility. Without Salamander, SimpleSkinBackport or Ears, skins are uploaded the way vanilla's model reads them
* With SimpleSkinBackport and without Salamander, slim arms from Wawel Auth's skins reach SimpleSkinBackport
* The skin layer settings moved to Salamander's config, which carries them over once
* Skin API version 2: the drawing types (skin layers, draw kinds, viewer settings) moved to Salamander's API
* Player heads given only a name find the server's own player of that name, online or recently seen, instead of a Mojang account of the same name; `name@provider` picks a player at a provider
* The server module is now off until `wawelAuthEnabled` is set in `server.json`, so a new server starts as a vanilla one instead of stopping for setup; servers whose `server.json` already enables it keep it on
* With the server module on, a server Wawel Auth can't run on (online-mode off, no `publicBaseUrl`) or a broken `server.json` now stops it cleanly before its world loads and says why, instead of exiting abruptly or crashing; clients no longer crash on a broken Wawel Auth config
* Fixed errors from ArmoredArms' outdated built-in Wawel Auth integration when equipping armor
* Fixed garbled skins on Model Citizens figures
* Player heads and offline accounts' local skins no longer read the account database or decode textures on every frame
* Regular and Maven development jars now bundle runtime libraries; embedded-DepLoader builds use the `slim` suffix
* Fixed dark player skins in account and texture previews
* Isolated account previews from custom player-renderer state while retaining renderer-provided effects
* Fixed downstream development environments missing WawelAuth runtime libraries
* Fixed account previews crashing with the Forge and LiteLoader Chat Bubbles mods
* Added compatibility with FoamFix's modern skin renderer and standalone Ears, including local offline skins
* Fixed unreliable account-picker interactions and improved account-row hover feedback
* Animated capes now animate in the upload confirmation preview
* Fixed back-facing player previews appearing darker than front-facing previews
* Isolated skin-upload preview caches from account skins and cleaned up temporary preview textures on close
* Fixed server-list data loss from concurrent saves and stale snapshots, with atomic writes and protection against overwriting failed loads
